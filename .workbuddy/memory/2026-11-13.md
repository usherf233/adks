## adks — ADK Go 脚手架架构设计（v1 定稿）

**背景**：用户要在 E:/adks 做一个 Google ADK（Go 版）脚手架，带 Web 界面配置 SQL / MCP / 插件，配置完能直接生成独立 Agent。

**已确认的四项架构分叉（用户拍板）**
1. 产物形态：配置即运行 + 可导出源码，两出口共享同一 IR
2. 编排范围：首版单 Agent 全配（不做多 Agent / Graph 画布）
3. UI 栈：纯 Go 单二进制（embed + HTMX/Alpine），无 Node 依赖
4. 数据模型：多项目工作台

**核心技术判断（后续复用）**
- ADK Go v2 **不支持 Agent Config（YAML）**，仅 Python/Java 有 → 配置层必须自造，这是本项目核心工作量
- 单一编译器双出口靠 **`//go:embed kit/*.go` 原样拷出** 实现（不做模板化），物理上只有一份实现，杜绝行为漂移
- Go 版无 OpenAPI toolset → 必须自研「声明式 HTTP 工具」（`functiontool.Config.InputSchema` + jsonschema-go 支持运行时建 schema）
- Go 版 artifact 只有 `InMemoryService` + `gcsartifact` → 本地文件制品服务需自研
- `mcptoolset.New` 返回的 toolset 是唯一可 Close 对象；`tool.FilterToolset` 包装器**关不掉连接** → 必须 `MCPHandle{Raw, Exposed}` 分离
- `session/database` 走 GORM，sqlite 要用纯 Go 驱动 `glebarez/sqlite`（`gorm.io/driver/sqlite` 依赖 CGO，违反单二进制约束）
- 前缀稳定五个支点：instruction 禁时间戳 / 工具按名排序 / map 遍历先排序 / embed YAML 原文 / `jsonschema.PropertyOrder` + golden 快照

**交付物**：`E:/adks/designs/adks-harness-design-v1.md`（910 行，15 章 + 2 附录 + 评审记录）
- 结构自检 15/15，生产级必答 12/12，可编码三门槛全过

## adks 代码实施完成（v0.1 可跑）

**交付形态**：`adks serve` 单二进制（112MB），三栏 Web 工作台，端口 7788。
代码结构：`manifest/`（类型+默认值+严格校验）、`kit/`（编译器，被 builder 直接 import 且 embed 导出）、`internal/{store,codegen,verify,api}`、`web/`（原生 JS，无构建）。

**关键实现事实（踩过的坑，后续必须记得）**
- ADK `session/database` **不会建表**，必须显式 `database.AutoMigrate(svc)`，否则一律 `no such table: app_states`
- `toolsearch` 的 `discoveredNames` 会直接对 `ReadonlyState()` 返回值解引用 → 探测用假 Context 必须返回非 nil 的空 state
- `genai.GenerateContentConfig.MaxOutputTokens` 是 `int32` 值类型，不是指针
- 导出工程的 `go build` 需要 `-mod=mod`，否则报 `updates to go.mod needed`；导出后跑一次 `go mod tidy`
- `functiontool` 参数经 JSON 往返后数字变 `float64` → 统一用 `asInt(any) int` 读
- 冒烟测试用单 goroutine `cmd.Wait()` + `exited` channel，进程早退立即失败，别等满超时

**前端两个必须记住的坑**
- `.tab-pane { display: flex }` 会盖掉 UA 的 `[hidden] { display: none }` → 三个 tab 内容同时渲染。必须显式写 `.tab-pane[hidden] { display: none }`
- SVG/内联元素没问题，但 flex 子项要 `min-width: 0`，否则中文按钮被压成竖排单字

**已验证闭环**（浏览器实测 Edge + Playwright，无需装 Chromium）
建项目 → 改表单 → 保存（issues 为空、token 估算）→ YAML tab 严格解析 → 运行校验（go build 10s / go vet 5s）→ 导出 25 文件 131KB 独立可编译 → 试跑无密钥报错呈现 → 删除项目。全程 0 控制台报错（除试跑 400 的预期响应）。

**未验证**：真实 Gemini 对话（无密钥）、真实 MCP 连接、HITL 确认往返前端交互。
**已知取舍**：窗口 <940px 时试跑栏隐藏（桌面工具，暂不做抽屉）。

## Web UI 重做（v0.2）

用户反馈「太简单」，做了整层重写：`web/index.html` + `styles.css`（全量重写，~950 行）+ `app.js`（全量重写，~1100 行）。

**设计系统**
- 双主题用 `html[data-theme=dark|light]` + 首屏内联脚本定主题，避免闪白；深色 `#06070c → #1d2230` 五级表面，浅色对应五级
- 强调色走蓝紫渐变（`--accent-grad`），只用在主按钮和 logo
- 分区卡片编号（01–06）+ 每区 issue 徽章，不展开也能看到问题在哪一节

**新增能力**
- 模型连通探测 / 会话存储探测按钮（后端 `/probe/model`、`/probe/sql` 之前没接）
- 项目过滤框 + ⌘K / `/` 聚焦、⌘S 保存
- 版本独立成 tab（原来塞在导出页）
- 生成文件按目录分组 + 体积
- 聊天工具调用变成可展开卡片（args 折叠），tool_result 按 callId 回填打勾/打叉
- YAML tab 底部实时行数/字符数
- <1080px 试跑面板变浮动抽屉且默认收起，可手动展开

**踩坑（重要）**
- `.field > label { justify-content: space-between }` 会污染 `<label class="check">`，把勾选框文字推到最右边 → 必须显式写 `.field > label.check { justify-content: flex-start }`
- flex 列容器里 `<button>` 会被拉伸到满宽 → `.field > .btn { align-self: flex-start }`
- `renderForm()` 每次增删都重建 DOM，会丢掉 details 展开状态和滚动位置 → 渲染前记录 `openState[] + scrollTop`，渲染后还原

**顺手修的 Go bug**：`ensureSQLiteDir` —— sqlite DSN 指向不存在的目录时报 `unable to open database file: out of memory (14)`，这句错误会把人指向内存而不是路径。现在开库前先 MkdirAll，`kit/session_test.go` 加了 3 个回归测试。
